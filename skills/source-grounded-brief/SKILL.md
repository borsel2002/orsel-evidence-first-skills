# Source-grounded brief
1. Name the buyer question and audience. Do not invent demand metrics.
2. Copy each source URL, retrieval date, and exact supporting passage.
3. Write the answer first; follow with Why, How, What.
4. Separate facts, inferences, and unverified claims.
5. Remove unsupported superlatives, em dashes, and empty buzzwords.
6. Have a human verify citations before publishing.
Use the existing content_prep and copy_lint primitives when installed.
